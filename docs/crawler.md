# TheaterCatalogBot — このロボットは何者か

演劇・舞台の**公演の日時と場所**を集める巡回ロボットです。日本語のページを1日1回だけ読み、
「いつ・どこで・何が上演されるか」だけを記録します。

このページは、ロボットが自分の名乗り（User-Agent）で示している案内です。

```
TheaterCatalogBot/0.1 (+https://github.com/ShoYaku/find-o-play/blob/main/docs/crawler.md)
```

## 運営者

**薬丸翔（ShoYaku）** ── 集める仕組みをつくり、責任を持っています。

匿名では運営しません。このページの下に書いた窓口は、すべてこの運営者に直接届きます。

## 集めるもの

- 公演の**題名**
- **上演の日付と時刻**
- **上演場所**（劇場・ホールの名前）
- そのページ自身の **URL**（必ずリンクを返します）

## 集めないもの（保存する場所そのものを作っていません）

- **画像**（チラシ・ポスター・舞台写真）── 通信の段で、画像は本文を1バイトも読まずに切断します
- **あらすじ・説明文・キャッチコピー**
- **評価・順位・おすすめ**

これは運用上の心がけではなく、保存できる項目の一覧に、そもそもそういう欄が存在しません。

## 表から見える入口しか使いません

ブラウザで普通にページを開いたときに読み込まれるものだけを読みます。
**画面が裏で呼んでいる内部の入口（いわゆる内部API）は、1つも叩きません。**
そういうコードが1行も存在しないことを、公開の自動検査で毎回確かめています。

## どれくらいの頻度で来るか

- 同じサイトへの次の取得まで、**最低3秒**あけます
- 1つのサイトへ行くのは、1回の巡回で**最大20回・あわせて最大600秒**まで
  （robots.txt を読む1回も、転送で移った各回も、再試行も、この20回に数えます）
- ふつうは robots.txt と一覧ページの**2回**で終わります
- 平均すると **1秒あたり 0.0002 回**ほどです

## robots.txt の扱い

- **必ず先に読み、禁止されている場所には通信そのものを発生させません。**
- robots.txt が読めなかったとき（通信失敗・5xx・401/403/405）は、
  「書いていないから自由」とは解釈せず、**そのサイト全体を見送ります**。
- 200 が返ってきても、返ってきたものが robots.txt ではなくふつうのページだった場合も、
  同じく**見送ります**（見せてもらえていないのと同じ扱いです）。
- robots.txt が**別のURLへ転送されている**とき（`http://` から `https://` へ、
  ドメインを `www` 付きに寄せる、など）は、**最大5回まで追いかけて、その先の robots.txt を読みます**
  （RFC 9309 が求めている最低回数です）。追いかけた各回も、上の**20回**に数えます。
  5回で終わらなければ「読めなかった」として、**そのサイト全体を見送ります**。
- `Crawl-delay` が書かれていれば、そのとおりに待ちます。速くはしません。

## `noindex` / `nofollow` / `noarchive` の扱い

収集ロボットは、**robots.txt の `Disallow` と `nofollow` に従い、取得と巡回を行いません。**
`noarchive` が指定された応答は保存しません。

`noindex` は「**検索結果に載せないでほしい**」という宣言であり、取得を禁じるものではありません
（この宣言は、**取得できて初めて読めるもの**です）。
当ロボットはこの宣言をその意味どおりに受け取り、
**取得は行いますが、当サイトの公演ページには `noindex` を付け、外部の検索エンジンには載せません。**

指定ごとの扱いは、次のとおりです。

| 指定 | どこに書かれていても | こちらの動き |
|---|---|---|
| `noindex` | 通信の見出し（`X-Robots-Tag`） | **取得します。**そこから作った公演ページに、こちらも `noindex` を付けます（検索エンジンには載りません。当サイトの中では、ほかと同じように探せます） |
| `nofollow` | 通信の見出し（`X-Robots-Tag`） | **そのページに書かれているリンクは、1本も辿りません。**（そのページ自身は取得します） |
| `none` | 通信の見出し（`X-Robots-Tag`） | **取得しません。**`none` は `noindex, nofollow` の略で、リンクを辿るなという指示を含むためです |
| `noarchive` | 見出しでも、ページの中の `<meta name="robots">` でも | **写しを1枚も保存しません**（取得はします） |
| `noindex` / `none` / `noarchive` | **ページの中の `<meta name="robots">`** | **素のHTMLからは、そのページの公演を1件も読み取りません** |

**なぜ見出しの `noindex` と、ページの中の `noindex` で扱いが違うのか。**
著作権法施行規則が「収集を拒む意思表示」として名指ししているのは、
**`robots.txt` という名前のファイル**と、**HTML の `<head>` の中に置くメタタグ**の2つで、
通信の見出し（HTTPヘッダ）はそのどちらでもありません。
こちらは**きつい側に倒して**、名指しされているほうは従来どおり尊重し、
名指しされていないほうも「検索に載せない」という中身のとおりに守ります。

**取り出すのは事実だけです**（題名・日付・会場・料金・公式サイトのURL）。
あらすじ・紹介文・画像は、この経路でも、ほかのどの経路でも、**保存する場所そのものがありません**。

## 止め方

robots.txt に次の2行を書いてください。次の巡回から、そのサイトには通信しません。

```
User-agent: TheaterCatalogBot
Disallow: /
```

robots.txt をさわれない場合や、掲載そのものを取り下げたい場合は、下の窓口へどうぞ。
