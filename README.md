# FIND O PLAY

演劇・舞台の**公演の日時と場所**を集めて、「今日どこで何が観られるか」を引ける形にする準備をしています。

運営者：**薬丸翔（ShoYaku）**

---

## 劇場・主催者のみなさまへ

このプロジェクトの巡回ロボット **TheaterCatalogBot** が、公演情報を読みに伺うことがあります。

**何を集め、何を集めないか、どれくらいの頻度で来るか、そして止め方**を、こちらに全文公開しています。

### → [ロボットについての案内（docs/crawler.md）](./docs/crawler.md)

**「うちには来ないでほしい」「この記載を消してほしい」「ここが間違っている」**というご連絡は、
下の窓口へお願いします。**確認の手続きや理由の説明を求めることなく、その場で対応します。**

### → [窓口（Issues）](https://github.com/ShoYaku/find-o-play/issues)
